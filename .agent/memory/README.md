# memory — 项目记忆

## 用途

把「踩过的坑、做过的决策、未完成的事项」落成可检索的持久记录，避免每次重新考古。

## 文件

| 文件 | 内容 |
| --- | --- |
| known-issues.md | 已知问题：影响、复现、建议修法、状态（open / fixed） |

## 记录规范

- **写入时机**：发现新问题、做出架构决策、修复已知问题、任务收尾。
- **格式**：每条含 状态 / 日期 / 影响 / 建议 四要素；用 [ ] / [x] 标记 open/fixed。
- **引用**：任务前先查；命中问题在回复中引用条目编号（如 KI-01）。
- **更新**：修复后改状态为 [x] fixed 并补一句修复方式，不删除历史。
